- [ ] Physical standard controller: analog triggers/stick, neutral gating, retry/restart/pause, disconnect/reconnect and coexistence with touch/keyboard.
- [ ] Actual listening through device speakers/headphones; engine, ambience and event mix. Successful decoding is not listening approval.

## Before any later deployment

1. Record actual device/browser/controller/listening results, resolutions, settings and limitations. Close only evidenced checks.
2. Preserve the actual approval ledger. Rebuild `release` only from explicitly approved routes and retain Works as default/fallback. A bot witness is not approval.
3. Re-run the documented checks after material changes; export `dist` without tools, caches, scripts, large diagnostics or pending forestry assets.
4. Review the concrete export and its exact manifest identities. Obtain separate explicit deployment authorization. Do not infer deployment consent from phase acceptance.

The local development port is not a deployment target. Browser storage is origin-scoped; switching between development ports isolates local bests without deleting either store.
