# Pocket Circuit desk materials

`desk-atlas.webp` is original AI-generated game artwork created with the built-in
OpenAI `image_gen` tool for this project. No third-party asset pack is included.
The source generated image remains in the task's generated-images library.

The tool returned a 1254 × 1254 PNG. Asset preparation resized it to 1024 × 1024
and encoded WebP at quality 88 (238,866 bytes). The renderer extracts four 512-pixel
quadrants once: walnut, ruled paper, teal book cloth and a sage cutting mat. Wood
UVs tile across the desktop. The images are material textures, not a flat track
background; driving surfaces, heights and scenery are actual 3D geometry.

## Final generation prompt

Use case: stylized-concept. Asset type: production game texture atlas for a
high-quality miniature toy-car racer rendered in real 3D. Generate one square
2048 x 2048 image divided into EXACTLY FOUR equal 1024 x 1024 seamless-material
quadrants, no gutters, no frames. Top left: rich warm walnut desktop wood,
flowing fine grain, subtle tiny scratches and pores, no planks, elegant medium
brown. Top right: ivory notebook paper with very subtle fibers, faint blue
horizontal ruled lines and one delicate coral margin line, no handwriting or
objects. Bottom left: deep dusty teal woven linen book-cover cloth, fine tactile
weave, lightly worn subtle texture, no text or ornaments. Bottom right: muted
desaturated dark sage green self-healing cutting mat with thin subtle ivory
square measurement grid, no text or numbers. Orthographic flat scan, perfectly
even diffuse illumination, no directional lighting, no shadows, no perspective,
no pictured objects. Sophisticated tactile stylized game materials, believable
miniature-world materials, detailed but visually quiet so cars are readable.
No logos, no lettering, no watermark. Quadrant edges exactly halfway horizontally
and vertically.
